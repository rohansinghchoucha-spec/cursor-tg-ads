## Platform groups

### A) Mainstream (powerful but locked for crypto trading)

- **Meta** — exchanges/trading/wallets-with-trade need written permission + regulatory license; Advantage+ AI strong but account risk high without approval.
- **Google** — exchanges/wallets need certification; ICOs/DeFi/presales often banned; Performance Max is AI but useless until certified.
- **TikTok** — crypto wallets/tokens/trading mostly restricted; use creators + Spark Ads carefully, not as primary DR.
- **X Ads** — many crypto categories need prior authorization; good for CT/trader mindshare once cleared.

### B) Crypto-native (fast path — recommended next after TG)

| Network | Why use | Targeting level |
|---------|---------|-----------------|
| Bitmedia | Low min, CPC/CPM, wallet/activity filters emerging | Geo + crypto context + wallet signals |
| Coinzilla | Premium crypto publishers, PR + display | Site/context + geo |
| Cointraffic | Managed + native crypto | Premium inventory |
| A-ADS / AADS | Tiny budgets, quick tests | Broad crypto |
| PropellerAds | Push/pop/native volume, crypto-ok | Geo + OS + AI bid |
| Blockchain-Ads / Slise / HypeLab | On-chain wallet cohorts | Token holders, DeFi actives |
| Brave Ads | Privacy browser, crypto-curious | Contextual / interest |

Payments often USDT — desk-friendly.

## High-level targeting model (think in layers)

```
L1 WHO   → Job-to-be-done: move fiat↔USDT, OTC volume, P2P desk clients
L2 WHERE → Channels they already live in (TG P2P, crypto news, CT, local money groups)
L3 WHEN  → Volatility / rate spikes / payday / remittance days
L4 PROOF → Speed + network (TRC20) + local rail (UPI/NGN/ARS) + trust signals
L5 GATE  → Lead bot qualifies volume before human close
```

### Audience tiers (spend priority)

1. **Hot** — USDT buy/sell searchers, P2P channel readers, OTC desks followers  
2. **Warm** — Active traders (BTC/USDT pairs), wallet on-ramp users, remittance corridors  
3. **Cold** — General crypto news readers → education funnel, not instant desk pitch  

### Geo corridors that historically fit USDT rails

- IN (UPI/IMPS), NG (NGN/Opay), LATAM (ARS/COP), MENA (local bank), SEA (GCash/PromptPay)  
- Match **payment hook in first line** of ad to geo.

## 30-day practical mix (if budget small)

Week 1–2 (fast learning):
- 60% Telegram TON Ads + lead bot
- 20% Bitmedia / A-ADS creative tests
- 20% 2–3 KOL / channel native posts

Week 3–4 (scale winners):
- Double TG channel packs that convert
- Add Propeller push only if CPA acceptable
- If wallet budget: test Blockchain-Ads / Bitmedia wallet segments
- Skip Meta/Google until license path clear

## Decision rule

- Need clients **this week** → Telegram + crypto nets + KOLs  
- Need **precision wallets** → Blockchain-Ads / Slise (higher $)  
- Need **mass scale brand** later → Meta/Google after certification  
- AI role everywhere → creatives + bid rules + pause losers; human closes desk deals
