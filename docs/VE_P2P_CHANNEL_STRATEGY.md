## World pattern: what winning P2P / DApp channels look like

Typical stack (Binance P2P style ads, Noones, wallet brands, OTC desks):

1. **Announcement channel** (clean, Spanish/local language)  
2. **Support bot / Mini App / DApp link** (Trust Wallet Browser)  
3. **Pinned welcome** — how it works, official links, scam warning  
4. **Utility posts** — rates, how-to, safety, product updates — not only “BUY NOW”  
5. **Discussion group** (optional) — community; channel stays official voice  

Ad creatives that work in VE-style markets:
- Utility: “USDT ↔ Bs / Pago Móvil / Trust Wallet”  
- No bank / local rail hooks  
- Speed + clear process  
- Avoid: guaranteed profit, flash USDT, ALL CAPS, “last chance”

## Telegram Ads — keep approval high

### Copy / creative (never)
- ALL CAPS words
- Guaranteed returns / “x100” / risk-free
- Fake urgency (“solo hoy”, “última chance”)
- Aggressive CTAs with !!!
- Unverifiable “#1 / mejor del mundo”

### Destination channel (never)
- Empty or only spam affiliate dumps
- Cloaking / bait-and-switch after review
- Scam language, seed-phrase asks, fake support
- Misleading brand names (Binance/Trust Wallet spoof)

### Destination channel (do)
- Clear about + Spanish description
- Pinned: official DApp link, bot, rules, “admins never ask seed”
- Regular non-ad posts (guides, updates, safety)
- Honest product: sell/buy USDT via Trust Wallet DApp
- Risk line: not financial advice / P2P risks exist
