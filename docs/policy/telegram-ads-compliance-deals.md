# Telegram Ads compliance for deals / phone channels

Based on official guidelines: https://ads.telegram.org/guidelines  
Applied to `@TimeDealsOfficial` workstream (Nov 2026).

## Hard bans relevant to this niche

| Section | Meaning |
|---|---|
| **5.12** | Questionable legality — includes **carding**, stolen/leaked data, counterfeit |
| **5.4** | Deceptive/misleading — false claims, clickbait, unsupported “best/cheapest”, mismatch ad vs destination |
| **5.7** | Paid product terms must be explicit (fees, payment, deadlines) |
| **4.4** | No cloaking / swapping destination content only to pass review |
| **4.5** | Channel needs recent post (within ~2 weeks of review) |
| **4.1 / 4.6** | Complete bio + profile; no gimmicky style destination |
| **2** | Ad text: no caps spam, emoji flood, unicode gimmicks, line-break abuse |

## Cheap / sasta / low rates — allowed?

**Yes IF real and matched.**

| Allowed | Risky |
|---|---|
| Exact ₹ in channel + same ₹ in ad | Only “cheap / dream / hurry” with no number |
| `Today ₹X (usual ₹Y)` if true | Absolute “cheapest in India / No.1” |
| `% off` with real compare price | Ad price ≠ channel price |
| Condition stated (Used/Open-box/New + bill) | “Brand New” at impossible price with zero proof |

Low price alone is not an automatic ban. **False or unprovable claims** are the problem.

## Destination checklist before launching ads

- [ ] Clean name (no carder/unicode spam)  
- [ ] Complete bio + avatar  
- [ ] Pinned rate list with exact models + ₹ + condition + payment  
- [ ] No hard-ban wording anywhere  
- [ ] Every public deal post has ₹ (or delete)  
- [ ] Media posts have captions  
- [ ] Return/refund / store policy 1–2 lines  
- [ ] Ad creative copies a real pinned offer  

## Post mix that matches compliant sellers

1. **Rate posts (majority)** — model + storage + ₹ + condition + COD/Prepaid  
2. **Booking confirms** — same fields + slots  
3. **Shipping/delivered proofs** — same model + paid ₹ (allowed; others use too)  

Shipping/review proofs are fine. Vague “dream product shipped” is not.
