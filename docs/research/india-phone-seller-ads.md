# India phone / deals sellers with Telegram Ads (research archive)

Research captured during Nov 2026 agent run. Sources: public Telegram channel previews + Telegram Ads spy archives (tgadsspy / related).  
**Not affiliate-loot focused** unless noted. Carding searches were refused / dropped per policy.

## A) India booking / COD / dealer-rate advertisers (confirmed ad activity in spies)

| Handle | Type | Notes |
|---|---|---|
| `@mobile_phone_cod_booking_bot` (Harsh Mobile) | COD booking bot | Strong ad days; dealer rate creatives |
| `@harshmobiles` | Seller/rate channel | Long ad activity stretch |
| `@sg_mobile_booking` | Booking + rates (~5K) | Exact model @price + EMI posts |
| `@mobile_booking_online` | Booking channel | iPhone/phone @ exact ₹ |
| `@deals_mobile_bot` | Reseller rate bot | Hindi dealer-rate ads |
| `@loot_mobile_bot` | Daily mobile rates bot | Reseller/wholesaler framing |
| `@trusteddeal_bot` | Advance booking bot | Rate list creatives |
| `@mobilewaledeals` | Phone offers channel | Long active days in archive |

### Typical post pattern (learn from these)

```
Model + storage @price
Coupon / bank EMI
Color links OR admin ping
Commission (if COD booking marketplace)
```
