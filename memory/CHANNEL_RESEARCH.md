1. **Members ≠ audience.** Agar 50k–100k members aur live post views ~1–100 → inflated → DROP.
2. **Famous crypto ≠ sellers.** Education/YouTube lanes already burned budget → DROP.
3. **China-pay / rate channels** historically best for this desk → prefer.
4. **CPM 4 TON** quality lane working; ultra-low CPM pehle zero delivery.
5. True KPI = **DM + deal**, not only dashboard Actions / channel joins.
6. Pehle DROP kiya hua channel sirf tab wapas jab **fresh live audit** reason overturn kare (jaise `@usdt_buy_seller_binance_p2p` delivery me top aaya).
